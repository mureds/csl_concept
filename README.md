# CSL — Coincidence Site Lattice (개념 시각화)

일치격자(CSL)·Σ·미스오리엔테이션·Brandon 기준을 배우는 교육용 사이트.

### 🔗 Live
- 시각화: https://mureds.github.io/csl_concept/
- 쉬운 설명: https://mureds.github.io/csl_concept/guide.html
- 수학: https://mureds.github.io/csl_concept/math.html

## 구성
- `index.html` — 2D 일치격자 시각화(회전 θ, 일치점) + **Σ–θ scatter 그래프**(Brandon 기준)
- `guide.html` — 쉬운 개념 설명
- `math.html` — 수학(회전·일치조건·Ranganathan Σ 생성식·Brandon), MathJax
- `js/csl2d.js` — 2D 엔진(격자·일치·Σ 급수·Brandon) · `js/main.js` — 시각화 배선

동일격자(same-lattice) 고전 CSL. 이종상 계면 도구는
[Cu//Cu6Sn5](https://mureds.github.io/csl_cu_cu6sn5/) · [Cu//G-phase](https://mureds.github.io/csl_cu_g/) 참고.
